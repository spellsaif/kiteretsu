# 0.1.0 Release Scope & Architecture

Kiteretsu **0.1.0** is the initial public release focusing on **local repository intelligence, MCP agent interoperability, and continuous code graph indexing**.

---

## 🎯 0.1.0 Core Capabilities

1. **Four-Signal Multi-Sensor Fusion**:
   - Lexical IDF-weighted keyword matching
   - Semantic vector embeddings
   - Symbol-level dependency and call graph traversal
   - Episodic task memory and Architectural Decision Records (ADRs)

2. **Standardized Agent Bridge & MCP Server**:
   - Native instruction management for **Claude Code**, **Cursor IDE**, **Gemini CLI**, **OpenCode**, **OpenAI Codex**, **GitHub Copilot**, and **Generic MCP Agents**.
   - Standalone MCP server (`@kiteretsu/mcp-server`) with 15 tools and 5 repository resources.

3. **Universal Resolution & Language Capability Tiers**:
   - **Tier A (Project-Aware)**: TypeScript, JavaScript, Python, Rust, Go (with `ProjectContext` discovering `tsconfig.json`, `package.json`, `Cargo.toml`, `go.mod`, `pyproject.toml`).
   - **Tier B (AST-Aware)**: Java, Kotlin, Scala, C/C++, Ruby, C#, PHP, Swift, Dart, Elixir, Lua, Zig, Julia, Objective-C, Vue, Svelte.
   - **Tier C (Syntax & Symbol Indexing)**: PowerShell, Verilog, SystemVerilog.

4. **Transitive Blast Radius & Code Explanation**:
   - Predictive impact calculation (`LOW`, `MEDIUM`, `HIGH`) and affected test discovery before editing code.
   - Deep explanation (`kiteretsu explain`) synthesizing AST, graph callers/callees, ADRs, rules, and tests.

5. **Canonical TypeScript Configuration (`kiteretsu.config.ts`)**:
   - Single source of truth for indexing guardrails and ignore patterns via `defineConfig({ ... })`.

---

## ⚠️ Known 0.1.0 Scope & Limitations

- **Ecosystem Depth**: Tier A languages feature dedicated package configuration adapters; Tier B languages perform AST-aware and candidate filesystem verification.
- **Local Storage**: Intelligence graph and memory are persisted in local SQLite WAL (`.kiteretsu/memory/kiteretsu.sqlite`). Cloud synchronization is planned for future releases.
- **Experimental Adapters**: Adapters for Aider, Windsurf, Trae, and Antigravity are roadmap items scheduled for upcoming iterations.
